# 인스타 제너레이터

**이미지 한 장 → 5초 영상(힉스필드) → 인스타그램 릴스 자동 게시**를 버튼 하나로 하는 로컬 웹앱입니다.
Node.js(npm 포함)만 있으면 됩니다. 처음 실행할 때 `npm install`이 자동으로 돌아 필요한 모듈(영상 합치기용 ffmpeg)을 설치해요 (1~2분).

> 패키지 관리자는 **npm**을 사용해요 (pnpm·yarn 말고). 직접 설치하려면 `npm install` 또는 `npm run setup`.

---

## 0. 준비물

| 항목 | 확인 방법 |
|---|---|
| Node.js 22 이상 (npm 포함) | 터미널에서 `node -v`, `npm -v` |
| 힉스필드 API 키 | https://cloud.higgsfield.ai → API Keys (Key ID + Secret), 크레딧 충전 |
| 인스타그램 **프로페셔널(비즈니스/크리에이터) 계정** | 인스타 앱 → 설정 → 계정 유형 |
| Meta 비즈니스 포트폴리오 | https://business.facebook.com |

## 1. 실행

- **Windows**: `start.bat` 더블클릭
- **Mac**: `start.command` 더블클릭 (또는 터미널에서 `npm start`)

브라우저에서 http://localhost:3000 이 열립니다.
처음 실행하면 `.env` 파일이 자동으로 생깁니다.

> 키 없이 흐름만 연습하기: `npm run mock` (과금·게시 없음)

## 2. 힉스필드 키 넣기

`.env` 파일을 열고 입력하세요.

```
HF_API_KEY_ID=발급받은 Key ID
HF_API_KEY_SECRET=발급받은 Secret
```

## 3. 인스타그램 토큰 받기 (통합 로그인 · Unified Login)

1. https://developers.facebook.com/apps → **앱 만들기**
   - 사용 사례: **Manage messaging & content on Instagram**
   - 앱 소유자: 내 **비즈니스 포트폴리오**
2. 앱 대시보드 → **사용 사례** → Manage messaging & content on Instagram → **맞춤 설정** → **API setup with Unified login**
3. **Create new configuration** → 기본 권한 그대로(`instagram_basic`, `instagram_content_publish` 포함) → 만료 기간 선택 → 저장
4. **Generate access tokens** → **Add account** → 내 인스타 계정을 **Instagram 테스터**로 초대
5. 인스타그램 **웹**에서 수락: 설정 → 웹사이트 권한 → 앱 및 웹사이트 → **테스터 초대**
6. 다시 대시보드에서 **Generate token** → 로그인 → 토큰 복사 (**한 번만 보여 줍니다!**)
7. `.env`에 붙여 넣기

```
IG_ACCESS_TOKEN=복사한 토큰
```

`IG_USER_ID`는 비워 두면 앱이 토큰으로 자동으로 찾아요.

## 4. 앱 다시 켜고 확인

창을 닫았다가 `start.bat` / `start.command`를 다시 실행하세요.
오른쪽 위에 **힉스필드 연결됨**과 **@내아이디**가 초록색으로 보이면 준비 끝입니다.

## 5. 사용

1. 이미지를 끌어다 놓습니다 (세로 9:16 권장)
2. 어떻게 움직일지 적습니다 (예시 버튼 클릭 가능)
3. 캡션을 씁니다
4. **영상 만들기** → 1~5분 기다리면 영상 미리보기가 나옵니다
5. 영상을 확인하고 **인스타에 게시** 또는 **게시 안 함**을 고릅니다

자동으로 게시되는 일은 없어요. 버튼을 눌러야만 인스타에 올라가요.

만든 영상은 `outputs/` 폴더에, 작업 기록은 `logs/jobs.jsonl`에 저장됩니다.

## 6. 텔레그램으로 쓰기 (선택)

폰에서 사진을 보내 영상을 만들고, 미리보기를 확인한 뒤 버튼으로 게시할 수 있어요.
PC에서 앱이 켜져 있기만 하면 되고, 포트포워딩·서버는 필요 없어요.

1. 텔레그램에서 **@BotFather** → `/newbot` → 봇 이름 정하기 → **토큰** 복사
2. `.env`에 `TG_BOT_TOKEN=복사한 토큰` 입력 → 앱 다시 켜기
3. 만든 봇에게 `/start` 보내기 → 봇이 알려 주는 **chat id**를 `.env`의 `TG_CHAT_IDS`에 입력 → 앱 다시 켜기
   (여러 명이면 쉼표로: `TG_CHAT_IDS=1234,5678`. 여기 없는 사람은 봇을 써도 아무 일도 안 일어나요)

**사용법**: 사진을 보내면서 사진 설명(캡션)에 움직임을 적어요. 인스타 캡션은 `---` 아래에 적어요.

```
천천히 카메라가 다가오며 머리카락이 바람에 날린다
---
오늘의 한 장 ✨ #reels
```

영상이 완성되면 미리보기와 함께 **[✅ 인스타에 게시] [✏️ 캡션 수정] [🔁 다시 생성] [🗑 취소]** 버튼이 와요.
텔레그램에서 시작한 작업은 버튼을 누르기 전까지 **절대 자동 게시되지 않아요.**
웹에서 시작한 작업도 완료·실패·게시 결과가 텔레그램으로 알림 와요 (끄려면 `TG_NOTIFY_WEB=0`).
`/status` 를 보내면 힉스필드·인스타·Claude 연결 상태를 알려 줘요.

### Claude 붙이기 (선택)

`.env`에 `OPENROUTER_API_KEY=sk-or-v1-...` 를 넣고 앱을 다시 켜면 텔레그램 봇이 똑똑해져요.

- **사진 + 하고 싶은 말** (예: "바다 느낌으로 잔잔하게, 캡션은 여름 감성") → Claude가 사진을 보고
  영상 움직임과 인스타 캡션을 정리해서 **[🎬 이대로 만들기] [🔁 다시 제안] [🗑 취소]** 버튼과 함께 보여 줘요.
  마음에 안 들면 "더 역동적으로" 처럼 글로 보내면 다시 정리해요. 사진만 보내도 돼요.
- `---` 로 직접 나눠 쓰면 Claude를 거치지 않고 바로 만들어요 (위 사용법 그대로).
- **사진 없이 말을 걸면** Claude가 대답해요 (캡션·해시태그·릴스 아이디어 등). `/reset` 으로 대화 기억을 지워요.
- 모델은 `CLAUDE_MODEL` 로 바꿀 수 있어요 (기본 `anthropic/claude-sonnet-4.5`). 사용량만큼 OpenRouter 크레딧이 차감돼요.

> 사진을 "사진"으로 보내면 텔레그램이 압축해요. 원본 화질이 필요하면 "파일"로 보내세요.
> 앱을 다시 켜면 그 전 작업의 버튼은 동작하지 않아요 (영상은 `outputs/`에 남아 있어요).

## 7. 팀 영상 합치기

팀원 각자 만든 5초 영상을 모아 한 편의 영상 **파일**로 만들어요 (인스타에 올리지 않아요).

**추천 진행 (4명 · 2분 영상)**
- 팀 주제를 하나 정하고, **기·승·전·결**을 한 명씩 맡아요 → 1명당 5초 × 6컷 = 30초
- 모두 같은 스타일 문구를 프롬프트 끝에 붙이면 한 편처럼 보여요 (예: `따뜻한 필름 톤, 느린 카메라 무빙`)

**1) 각자** — 영상을 만들고 확인한 뒤 **⬇️ 영상 저장**을 눌러요.
파일 이름 앞에 순서를 붙여서 팀장에게 보내요 (공유 폴더·메신저 등):

```
01_기_민수.mp4  02_기_민수.mp4 … 07_승_지영.mp4 … 19_결_현우.mp4 …
```

**2) 팀장** — 오른쪽 위 **팀 영상 합치기 →** (http://localhost:3000/merge)
1. 받은 mp4 파일을 한꺼번에 끌어다 놓기 → 파일 이름 순서대로 정렬돼요
2. 필요하면 끌어서 순서 바꾸기 · ✕ 로 빼기 (내가 만든 영상은 **추가** 버튼으로)
3. 화면 비율(세로 9:16 / 가로 16:9 / 정사각)과 컷 전환(페이드) 고르기
4. **영상 합치기** → 1~3분 → **⬇️ 영상 파일 저장**

- 사진 비율이 달라 영상 크기가 제각각이어도 괜찮아요. 가운데에 맞추고 빈 곳은 흐린 배경으로 채워요.
- 0.3초 페이드 기준으로 **2분을 채우려면 약 25컷**이 필요해요 (컷마다 전환 시간만큼 겹쳐요).
- 받은 클립은 `outputs/team-inbox/`, 합친 영상은 `outputs/team-merged/`에 저장돼요.
- 소리는 넣지 않아요. 음악은 합친 파일을 편집 앱에서 추가하세요.

## 자주 나는 오류

| 메시지 | 해결 |
|---|---|
| 힉스필드 오류 (401) | Key ID / Secret 오타 확인 |
| 힉스필드 … nsfw | 다른 이미지 사용 (사람 노출·유명인 등은 거부될 수 있음) |
| 토큰에 연결된 인스타그램 계정이 없습니다 | 3번의 4~6단계(테스터 초대 수락) 다시 확인 |
| 인스타그램 오류 (code 190) | 토큰 만료 또는 오타 → 새로 발급 |
| ffmpeg 없음 — npm install 필요 | 앱 폴더에서 `npm install` 실행 (인터넷 필요). 학교망에서 막히면 ffmpeg 를 설치하고 `.env` 에 `FFMPEG_PATH=ffmpeg.exe 경로` |
| 포트 3000 이 이미 사용 중 | 앱이 이미 켜져 있음. 기존 창을 닫거나 `.env`의 `PORT` 변경 |

## 참고

- 하루 게시 한도: 계정당 24시간에 API 게시 100건
- 게시물에는 `IG_AI_LABEL=1`(기본)으로 **AI 생성 라벨**이 붙습니다
- API 키가 담긴 `.env`는 절대 다른 사람에게 보내거나 업로드하지 마세요
- 구조: `lib/higgsfield.mjs`(영상) · `lib/instagram.mjs`(게시) · `lib/pipeline.mjs`(흐름) · `server.mjs`(웹서버) · `public/index.html`(화면)
  → 텔레그램 봇을 붙일 때는 `lib/pipeline.mjs`의 `startJob()`만 호출하면 됩니다
